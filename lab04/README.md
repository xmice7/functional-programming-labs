# Лабораторна робота №4. Рекурсія та мемоізація в Python

**Варіант 6 — Підрахунок суми вкладеної структури.**
Рекурсивне обчислення суми та кількості елементів у вкладених списках/кортежах.
Дослідження: максимальна глибина вкладеності, ітеративна альтернатива з власним стеком, переповнення стеку викликів (`RecursionError`).
Методичні алгоритми: quicksort (чистий та гібридний), обходи бінарного дерева, мемоізація Фібоначчі через `lru_cache`.
